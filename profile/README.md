We build a cross-platform **visual editor for LaTeX** — real TeX underneath, a live
document on the surface. It runs where you already write, including **Microsoft
Office** and **WPS**, and it is **open source**: the replacement MathType should
have had.

**Visual, not compiled**<br>
Edit equations as they will appear; the LaTeX source stays canonical.

**Embedded, not images**<br>
Native equation objects in Office and WPS on Windows and macOS.

**Open, not rented**<br>
The editor is open source, so your documents are never held hostage.
